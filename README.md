# Website Health Checker
A lightweight Python package for checking website availability, response times, and HTTP status codes.

## Overview
Website Health Checker is an open-source Python project designed to help users check whether a website is reachable and inspect its HTTP response.

## Project Status
This project is currently under development. Features, APIs, and usage instructions may change as development progresses.

## Planned Features
- Check website availability.
- Measure HTTP response times.
- Inspect HTTP status codes.
